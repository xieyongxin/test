# Teammate 可复用回归用例

[返回项目入口](../README.md) · [用例库](cases.md)

用于保存跨批次复用的用例设计，不保存每次实际执行结果。当前尚无正式回归用例。

- 使用项目内唯一的 REG 编号，例如 REG-001；记录修订号、来源需求/批次、适用条件、步骤和预期。
- 从批次沉淀时记录原 TC 编号和版本，核实适用范围后加入；待核实条目不得默认当作有效覆盖。
- 每次回归将选定用例复制到批次用例文档，分配该批次 TC 编号，注明 REG 来源及修订号，形成执行快照。
- 回归库修改时提升修订号，记录变更和影响；不能自动改变历史批次内容或沿用旧执行结果。
- 失效用例注明原因和替代编号，保留编号与来源，不重复分配。
