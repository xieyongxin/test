# 模板使用说明

将 [batch](batch/README.md) 所在的整个目录复制到项目 `batches/YYYY-MM-DD-topic/`。请复制目录而非只复制索引，这样内部相对链接保持有效。公共规范和项目规则从项目入口进入，批次模板无需修改公共路径。

## 填写顺序

1. 填写批次索引，更新项目批次列表，确定负责人、范围、环境和构建。
2. 按需要填写需求和计划，编写用例；至少维护索引、用例和执行记录。
3. 有真实执行后填写 RUN 记录；发现问题登记 BUG；需要最终结论时填写报告并交人工确认。
4. 为附件、证据登记可定位来源；结束时更新索引和项目批次列表。

模板中的“待分配”“待补充”“待指定”“待确认”“待统计”都是占位说明，不是已发生的事实。各文档的条目块可重复复制，分配实际编号后替换标题。未使用的空白条目不计入需求、用例、执行或缺陷数量。

保留按需文档文件以保证导航可用；不适用时在索引说明原因，并在该文档开头注明“不适用：原因”，不必填写剩余条目。尚未取得必要信息属于待补充，不属于不适用。

模板仅含填写骨架，不包含真实需求、测试结果或人工结论。规则详见[测试流程](../docs/testing-workflow.md)与[结果规则](../docs/results-and-review.md)。
