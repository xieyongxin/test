## 开始本项目测试

1. 补充项目说明，读取项目规则及[公共流程](../../docs/testing-workflow.md)。
2. 将根目录 `templates/batch/` 整体复制到本项目 `batches/YYYY-MM-DD-topic/`。
3. 填写批次索引并更新[批次列表](batches/README.md)。
4. 按需求、用例、执行、缺陷和报告建立追溯，复测保留历史，最终结论由人工确认。
