# APILink 项目规则

适用范围：本项目目录及子目录。先遵守[根目录 Agent 规则](../../AGENTS.md)和[公共规范](../../docs/conventions.md)，再读取[项目说明](overview.md)与目标批次索引。

## 当前约定

- 项目目录标识为 `apilink`，展示名称为 APILink。
- 测试资料按 `batches/YYYY-MM-DD-topic/` 归档，新批次使用[公共模板](../../templates/README.md)。
- 负责人待指定；业务事实、环境、验收要求和其他专属规则待补充。不得根据其他项目记录推断本项目事实。
- 当前没有额外的业务测试要求；后续补充必须注明依据、适用范围和生效日期。
- 项目规则不得弱化公共证据要求或人工确认要求；冲突时先澄清受影响内容。
