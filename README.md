```text
  README.md                   项目导航与负责人

  regression/                可复用回归用例

```

## 日常使用

1. 读取公共规范和目标项目规则，检查本地修改；已配置远端时先同步，保留其他成员的改动。
2. 将 `templates/batch/` **整体复制**到目标项目的 `batches/YYYY-MM-DD-topic/`。日期取批次创建日期，主题使用简短英文小写词，单词以 `-` 连接。
3. 填写批次索引，至少维护索引、用例和执行记录。其他材料按需使用，在索引中写明不适用原因。
4. 从需求来源整理分析和用例；实际执行后记录结果、环境、版本和证据，问题关联缺陷。
5. 复测新增执行记录；结束时确认剩余风险和未覆盖内容，需要测试结论时填写报告并由人工确认。
6. 更新批次列表；提交前检查链接、记录一致性和敏感信息，一次提交只围绕一个主题。

首次使用请补充各项目负责人、成员代号、业务范围和测试环境。环境说明只保存访问方式及凭据获取渠道。

## 接入新项目

参考三个现有项目的目录结构，创建唯一的小写英文目录，并建立项目导航、说明、规则、知识、回归和批次入口。只复用结构和公共说明，不复制其他项目的事实资料。补充本页项目表，按公共批次模板开始记录。

当前只约定本地协作方式，不要求特定远端平台、分支审核机制或自动化流水线。此仓库的文件初始化不代表已经提交或推送。
